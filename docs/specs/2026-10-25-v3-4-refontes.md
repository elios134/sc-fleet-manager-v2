# Refonte de 4 pages — v3.4 (spec)

Maquette validée par André le 25/10/2026 (`docs/design/maquettes-refonte-pages.html`, variante A
pour chaque page). Spec validée le 25/10/2026.

## Objectif
Aligner Cosmétiques, Ma flotte, CCU et Minage sur le modèle « liste + fiche fixe large » du
Catalogue v3.3 (ou un parcours guidé pour le Minage), pour que l'app se lise partout de la même
façon. Réussi quand les 4 pages s'utilisent sans fenêtre modale pour consulter, avec une fiche
de 440 px (520 px sur grand écran) à droite.

## Ce qui existe déjà (vérifié)
- **Cosmétiques** (`pages/Items`, 250 l.) : `get_hangar_items` (HangarItem + `pledgeName` par
  `LEFT JOIN Pledge`) ; groupes par pack, puces de type (`KIND_META`, kinds RSI « FPS Equipment »,
  « Skin », « Component », « Hangar decoration », reste = Autre ; 64/141 objets sans kind),
  pagination, 2 modales (objet, pack). Couleurs de type écrites en dur dans `KIND_META`.
  `Pledge` a `currentValueUsd`, `createdDate`, `isUpgraded`, `isBuybackable` (pas d'info
  « échangeable / melt » fiable).
- **Ma flotte** (`pages/Fleet`, 216 l.) : `get_ships` (ShipRow : specs ShipData, assurance,
  valeur du pledge, acquisition, location), `get_fleet_stats` (valeur totale, nb, LTI, prochaine
  expiration) ; grille/liste, filtre catégorie RSI + LTI, tri valeur/nom/assurance, modale
  `ShipDetailsModal` (partagée avec PackDetail), modale d'ajout, prolongation de location.
- **CCU** (`pages/CcuChain`, 368 l.) : `get_ccu_ships_metadata`, `find_ccu_paths` (chemins,
  économie, warbond), liste de souhaits (`wishlist_list` / `wishlist_toggle`), sélection
  départ/cible par `ShipPickerModal`, cartes de chemins dépliables, tri coût/économie.
- **Minage** (`pages/Mining`, 113 l.) : 6 blocs empilés (`OreInput`, `ScanValue`,
  `RefineOptimizer`, `RefineryLocations`, `SellRecommendation`, `WorkOrderSummary`), registre
  statique + prix UEX (`get_refinery_sell_prices`).
- **Liens** : le Loadout et le Comparateur lisent `?ship=<shipDataId>` ; la page 3D et les
  Assurances ne lisent aucun paramètre.
- Briques réutilisables v3.3 : fiche fixe du Catalogue (`ItemsTab` + `ItemDetailBody`),
  `Dropdown` (recherche intégrée), `placeStop`.

## Fonctionnalités

### 1. Cosmétiques — liste + fiche
- Barre : recherche (titre, pack), compteur « N objets · M packs », bouton de synchro existant.
- Puces de type avec compteurs : Tout, Équipement FPS, Peinture, Composant, Objet de hangar,
  Non classé.
- Tableau : objet (vignette RSI ou icône), type, « Pour » (vaisseau tiré du titre « Vaisseau -
  Peinture » quand il existe), pack d'origine. Par paquets de 60.
- Fiche fixe : grande image, type, pack d'origine, valeur du pack (`currentValueUsd`), date
  d'achat, vaisseau concerné avec pastille « dans ta flotte / pas dans ta flotte », boutons
  « Voir le pack » (page détail du pack existante) et « Ouvrir sur RSI ».
- Écart à la maquette : la ligne « Échangeable (melt) » est retirée (donnée absente).
- Couleurs de type → jetons du thème (fin des hex dans `KIND_META`).

### 2. Ma flotte — bandeau + liste + fiche
- Bandeau : vaisseaux, valeur (prix RSI), cargo total, équipage max, assurances courtes
  (< 12 mois et sans LTI).
- Barre : recherche, puces de catégorie (filtre existant), tri existant, « + Ajouter un vaisseau ».
- Tableau : vaisseau (vignette, fabricant), classe, équipage, cargo, assurance (pastille LTI /
  courte), prix RSI ; les locations affichent leur échéance.
- Fiche en fenêtre (choix d'André le 26/10/2026 au lieu de la fiche fixe, tableau pleine largeur) : image, classe, assurance, intérieur visitable, caractéristiques (longueur,
  équipage, cargo, SCM, bouclier, coque, DPS), location (prolonger / échéance), raccourcis
  **Loadout** (`?ship=`), **Vue 3D** (`?ship=`, nouveau paramètre lu par la page 3D),
  **Assurance** (onglet Assurances), suppression du vaisseau (confirmation).
- La modale `ShipDetailsModal` reste pour la page détail d'un pack.

### 3. CCU — sélection en ligne, frise, souhaits
- En-tête : « Je pars de » / « Je veux » en `Dropdown` cherchables (pastille « dans ta
  flotte »), coût de la montée directe. Fin de `ShipPickerModal`.
- Chemin sélectionné en frise horizontale : vaisseaux (possédé / cible), coût de chaque étape,
  étiquette warbond / stock limité, économie totale ; bouton « Ouvrir les CCU sur RSI » existant.
- Autres chemins en liste compacte cliquable (tri coût / économie existant).
- Fiche fixe à droite : liste de souhaits (statut warbond / stock limité / en vente), clic =
  devient la cible, « + Suivre un vaisseau ».

### 4. Minage — parcours en étapes
- 4 étapes cliquables : 1 Extraire (`OreInput` + `ScanValue`), 2 Raffiner (`RefineOptimizer`
  + `RefineryLocations`), 3 Vendre (`SellRecommendation` + itinéraire vers le point de vente),
  4 Fabriquer (lien vers le Crafting, liste des matériaux raffinés du work order).
- Boutons Précédent / Suivant ; étape mémorisée (`mining.step`).
- Bilan fixe à droite : `WorkOrderSummary` (valeur brute, raffinage, vente, profit net).

## Architecture
- **Logique pure (tests à côté)** :
  - `pages/Items/lib/cosmetics.ts` : `cosmeticKind(item)`, `shipOfTitle(title)`,
    `viewCosmetics(items, filtre)`, `kindCounts(items)`.
  - `pages/Fleet/lib/fleetView.ts` : `fleetKpis(ships)`, `insuranceTone(ship)`.
  - `pages/CcuChain/lib/chain.ts` : `chainNodes(path, ships)` (nœuds + coût par étape + étiquette).
  - `pages/Mining/lib/steps.ts` : `stepsState(workOrder)` (étapes faites / courante).
- **Composants partagés** : `components/ui/SidePanel.tsx` (aside fixe large réutilisé par les
  4 pages et le Catalogue) ; `components/ui/DataTable` non créé (tables propres à chaque page).
- **Interface** : réorganisation des `index.tsx` ; la page 3D lit `?ship=<shipDataId>`.
- **Rust** : `get_hangar_items` renvoie aussi `pledgeValueUsd` et `pledgeCreatedDate` (SQL
  paramétré, même requête).

## Erreurs et cas limites
- Hangar vide / non synchronisé : état vide avec bouton de synchro (existant).
- Flotte vide : état vide « Ajouter un vaisseau » ; vaisseau sans données ShipData : specs « — ».
- CCU : catalogue non synchronisé (état vide existant) ; aucun chemin : message + montée directe.
- Minage : aucun minerai saisi → étapes 2-4 désactivées avec explication ; prix UEX absents →
  message dans l'étape Vendre.
- Fenêtre étroite (< 1024 px) : la fiche passe sous la liste.

## Sécurité et confidentialité
Aucune donnée nouvelle envoyée au réseau ; seule lecture locale supplémentaire (valeur et date
du pack).
